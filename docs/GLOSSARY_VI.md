# Bảng thuật ngữ tiếng Việt — Thean store

Mọi chữ hiển thị trên giao diện phải là tiếng Việt và dùng đúng thuật ngữ dưới đây để thống nhất.
Tên thương hiệu lấy từ `src/config/brand.js` (`brand.name` = "Thean store", `brand.shortName` = "Thean",
`brand.clubName` = "Thean Club"). Không viết chữ "adidas" / "adiClub" trên giao diện.

Quy ước:
- Giữ nguyên tên mẫu sản phẩm (Samba OG, Ultraboost, Adizero…) và đơn vị size (US, EU, UK, cm).
- Tiền tệ hiện giữ USD (`formatPrice`), ngày tháng định dạng `vi-VN`.
- Chữ in hoa vẫn dùng class `uppercase` của CSS (không gõ tay chữ hoa) để giữ dấu tiếng Việt đúng.
- `aria-label` và nội dung toast cũng phải là tiếng Việt.
